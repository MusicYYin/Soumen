## 接续次序

1. 实机测金蝶砍树：分别进入难度选择和砍树界面，记录界面日志、目标位置、实际打击结果，并检查中途取消、关开关、切图。
2. 从运行时 DLL 中按功能提取调用链；先处理无需不明 Opcode 的 UI 和已有客户端结构功能，如自动修理、小地图视距、TP 面板。每项加入独立配置与清理。
3. 针对含网络封包的理符/金蝶旧实现等，确定当前国服版本、Opcode 来源和包结构后再连接发送入口。未知版本禁用相关功能。
4. 针对内存钩子和修改动作的战斗/位移功能逐项核对签名、结构和恢复逻辑，不将未验证功能暴露为可用开关。
