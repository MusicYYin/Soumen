# I-Ching 功能移植

范围以 I-Ching 插件本体 0.1.6.6 的用户界面为准。原版鉴权版本号 1.0.0.0 与本体版本号各自独立。新功能均从 Soumen 左侧“工具”打开，初始状态均为关闭。

| 功能 | 入口与实现 | 版本确认方式 |
| --- | --- | --- |
| 移速、最大加速度 | 原生移动速度计算与加速度更新 Hook | 从运行中的 0.1.6.6 采集两个地址和原始字节 |
| 强制移动、防击退、掉落无伤、无掉落 | 原生许可、击退、坠落回调 Hook | 同上 |
| 飞天遁地 | 本地高度调整与普通／战斗移动包 Hook | 同上；关闭和卸载时还原本地高度 |
| 无视魅惑恐惧、状态屏蔽（滑冰） | 强制动作、状态列表与状态包 Hook | 同上；状态过滤仅处理自身 |
| 移动读条 | 发送包 Hook，检测当前客户端移动包编号 | 使用签名扫描；客户端模块大小不符时关闭 |
| 技能距离、目标圈大小、后摇可移动、突进无位移 | 技能距离、目标半径、动作后摇与动作位移 Hook | 从运行中的 0.1.6.6 采集地址和原始字节 |
| 复唱缩减、咏唱缩减 | 技能计时与咏唱进度 Hook | 采集时原版未实例化；使用签名扫描并验证模块大小 |
| 取消钓鱼动画 | 资源同步／异步加载 Hook，替换 96 条钓鱼动画路径 | 从运行中的 0.1.6.6 采集入口和路径集合 |
| 战场透视 | PvP 玩家屏幕投影与阵营判断；透视线、职业图标、战意图标独立开关 | 原生 Hook 不需要；关于页诊断记录附近人数和阵营分布 |

所有已采集地址先核对进程主模块大小及函数原始字节；不匹配时保持关闭并写入诊断记录。如果原版 I-Ching 对应 Hook **实际启用**，Soumen 等待该 Hook 关闭，避免同一入口重复安装；仅有程序集留在进程中不会阻止接管。诊断模式记录工具开关、接管结果、阻止原因及已开启功能的周期状态。咏唱、复唱和移动读条签名尚未取得用户游戏内成功反馈，安装结果也会进入诊断记录。

参考资料：原生入口和功能范围来自用户提供的 I-Ching 0.1.6.6 程序及 Hook 快照；部分游戏结构和运动条件参照 [KeitaToolbox](https://github.com/zhui-zi/KeitaToolbox)（MIT）。
