# Soumen 工具

左侧“工具”分为概览、移动、战斗、其他、战场及功能状态检查。概览上方列出已启用的功能，可直接点击“关闭”；下方显示收藏。点击各功能右侧星号即可加入／移出收藏。收藏内容、功能开关及参数均保存到 Soumen 配置，下次进入游戏自动恢复。功能状态检查只验证原生入口是否与当前客户端匹配，不会为检查而启用 Hook，也不依赖功能开关；“可用”不代表已开启。移速按基础速度的倍率计算，1.0 倍为原速，可调到小数点后两位；技能距离可额外增加 0～3 yalms，目标圈参数为在原始半径上增加的距离。飞天遁地高度可快捷设置为 -7 或归零。

功能状态检查每 5 秒刷新一次。“可用”表示模块与原始字节或动态签名匹配，“入口被占用”表示检测到其他插件当前接管了同类 Hook，“不可用”表示验证失败；战场透视使用 UI 绘制，没有原生 Hook。能从游戏资源仓库读取版本时会显示游戏版本，读取不到便省略。

| 功能 | 实现 | 生效条件 |
| --- | --- | --- |
| 移速、最大加速度、强制移动、防击退、掉落无伤、无掉落 | 游戏内原生移动计算和状态入口 | Hook 地址、模块大小与原始字节匹配 |
| 飞天遁地 | 普通／战斗移动包中的高度字段 | 同上；只偏移发出的高度，本地角色画面保持原位 |
| 无视魅惑恐惧、状态屏蔽（滑冰） | 强制动作和角色状态入口 | 同上；状态过滤只处理自身 |
| 移动读条 | 发送包入口和当前移动包编号 | 签名及客户端模块匹配 |
| 技能距离、目标圈大小、后摇可移动、突进无位移 | 技能距离、目标半径和动作入口 | Hook 地址、模块大小与原始字节匹配 |
| 复唱缩减、咏唱缩减 | 技能计时与咏唱进度入口 | 签名及客户端模块匹配 |
| 快速结印（忍者） | 复唱缩减中的独立选项，针对连印动作 18805／18806／18807 | 需开启复唱缩减；不修改起手印的 20 秒充能 |
| 取消钓鱼动画 | 资源同步／异步加载入口，重定向指定动画 | 已切换钓鱼职业并进入采集状态 |
| 战场透视 | 已加载敌方玩家的屏幕绘制；透视线、职业图标与战意图标各有开关 | PvP 地图内 |

原生入口来自用户提供的游戏内 Hook 快照；游戏更新后若模块大小或函数字节不同，Soumen 会停止安装对应 Hook 并在诊断日志说明原因。其他插件仍在使用相同入口时，Soumen 暂停该入口，避免重复安装。关闭其他插件的 Hook 后可重新接管；更改显示名称不会消除原生入口冲突。

“关于 → 开发者模式 → 采集 Hook 快照”可以选择当前已加载的插件程序集，采集其 Hook 地址、启用状态和参数签名。采集器可沿插件实例成员、Hook 管理器和静态字段查找 Dalamud Hook；只记录 Hook 元数据，不导出其他配置字段。没有可访问的静态入口或使用其他 Hook 实现的插件可能返回 0 条，需要另行分析。部分游戏结构的实现参考 [KeitaToolbox](https://github.com/zhui-zi/KeitaToolbox)（MIT）。
